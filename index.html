• รูปแบบเสื้อ: เสื้อโปโล / เสื้อยืด / เสื้อทีม / เสื้อบอล ฯลฯ — ใส่รูปตัวอย่างไว้เลือกง่าย
• คอเสื้อ: กำหนดราคาที่นี่ เช่น คอกลม=129,000 / คอวี=139,000 / คอปก=145,000 — เลือกในออเดอร์ราคาจะเข้ามาเอง
• เนื้อผ้า: ไมโคร / TC / TK / Cotton ฯลฯ — กำหนดต้นทุนเริ่มต้นต่อตัว (เปลี่ยนได้ตอนทำออเดอร์)
• แขนเสื้อ: แขนสั้น = +0, แขนยาว = +ราคาเพิ่มต่อตัว
• โปรโมชั่น: สร้างโปรโมชั่นใหม่ได้เรื่อยๆ เช่น "10 แถม 1", "สั่ง 50 ตัวลด 5,000"
